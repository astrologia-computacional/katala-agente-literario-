Configurar API Key

Necesitas una API key de Anthropic para que el análisis funcione. Obtenla en console.anthropic.com. Se guarda solo en tu navegador, nunca se envía a ningún servidor externo.

Cargar desde Google Drive

Para cargar desde Drive, exporta tu documento como archivo .txt desde Archivo → Descargar → Texto sin formato, y luego súbelo aquí.

O si usas este sistema desde Claude.ai con Google Drive conectado, puedes pegar el texto directamente en el área de texto del manuscrito.
